# Reproducible-Research-Project

This repository contains the original R script and an adequate version in Jupyter Notebook of the Econometrics project. The project analyzes and models the IMDb ratings of different streaming shows using various econometric and machine learning tools. 

## Dataset information
Dataset source: Kaggle webpage
Link: https://www.kaggle.com/datasets/amritvirsinghx/web-series-ultimate-edition 

## Contents

- Original Script - Econometrics Project.r — original R script
- Updated Script - Python.ipynb — Jupyter Notebook version of the original script
- scripts/ - folder containing both scripts
- data/ — folder containing a dataset used in the analysis
- requirements.txt — Python packages requirements
- install_packages.r - R file for installation of necessary packages

## Setup Instructions
Before running a code:
- check the version of R/Python
- install packages if not present
- import packages
- make sure data file path is correct 

Detailed information about projects steps can be found in the file comments.
